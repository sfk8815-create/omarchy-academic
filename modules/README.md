# 第三方可选模块

这些模块来自社区开源项目，**默认不安装**，由 `install.sh` 交互式询问或通过 `--with-*` 参数启用。每个模块都保留了上游来源与许可证说明。

| 模块 | 来源 | 许可证 | 说明 |
| --- | --- | --- | --- |
| `zh-ui/` | [QueedWen/omarchy-zh-cn](https://github.com/QueedWen/omarchy-zh-cn) | MIT | Omarchy 界面简体中文化（菜单/面板/天气/快捷键） |
| `lunar-calendar/` | [GaryLiuGTA/omarchy_chinese_lunar_calendar](https://github.com/GaryLiuGTA/omarchy_chinese_lunar_calendar) | MIT | 状态栏农历日历（替换内置时钟） |
| `openscience/` | [ai4s-research/open-science](https://github.com/ai4s-research/open-science) | MIT | Open Science Desktop：本地优先 AI 科研工作台（osd CLI） |
| `sovena/` | [sfk8815-create/sovena](https://github.com/sfk8815-create/sovena) | MIT | 缙云文采文献流系统（Zotero→语义检索→MCP） |
| `mcp-cockpit/` | [sfk8815-create/mcp-cockpit](https://github.com/sfk8815-create/mcp-cockpit) | 见仓库 LICENSE | MCP 统一网关管理台 + 自愈看门狗 |

详细分析见 [docs/resources.md](../docs/resources.md)。
